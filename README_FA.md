# Helios | FX Obligation — نسخه ۲ (بدون Google Cloud)

این نسخه برای Google Sheets تنظیم شده و **بدون سرویس‌اکانت، JSON Key، Google Cloud یا Secrets** از تب `Rates_Log` می‌خواند. هیچ نرخ فرضی در داشبورد وارد نمی‌شود؛ تاریخچه و ورود داده‌ها در شیت باقی می‌ماند. در صورت نیاز فقط خروجی CSV به عنوان روش پشتیبان قابل آپلود است.

## اتصال در یک دقیقه

1. شیت اصلی را باز کن: `https://docs.google.com/spreadsheets/d/1xckakJWtevb91dqlpbW504SbLg2irhhxlIRHIuTF3Ow/edit`
2. روی **Share** کلیک کن، پایین پنجره **General access** را روی **Anyone with the link** بگذار و **Viewer** را انتخاب کن، سپس **Done**.
3. به اپ Streamlit برگرد و روی **↻ به‌روزرسانی از شیت** کلیک کن. **نیاز به Google Cloud، API key یا Streamlit Secrets نیست.**
4. هر بار نرخ جدید را در یک ردیف جدید `Rates_Log` وارد کن؛ اپ تغییرات را به‌صورت خودکار حداکثر حدود ۲ دقیقه بعد می‌خواند، یا با دکمه فوراً به‌روز کن.

## روش جایگزین: انتشار فقط یک تب

اگر نمی‌خواهی کل فایل Sheet با «Anyone with the link» قابل مشاهده باشد، می‌توانی فقط تب `Rates_Log` را به شکل CSV منتشر کنی:

1. در Google Sheets برو به **File → Share → Publish to web**.
2. گزینه **Link**، تب **Rates_Log** و فرمت **Comma-separated values (.csv)** را انتخاب کن، سپس **Publish**.
3. لینک ایجادشده را از بخش کناری **تنظیمات اتصال و روش جایگزین** در فیلد «آدرس خروجی CSV منتشرشده» قرار بده.
4. برای ثبت دائمی لینک در Streamlit، می‌توانی فقط این یک خط را در **App → Settings → Secrets** بگذاری:

```toml
published_csv_url = "لینک واقعی خروجی CSV منتشرشده"
```

این فقط یک لینک عمومی است، هیچ اطلاعات هویتی یا حساب سرویس لازم ندارد. *پس از هر بار راه‌اندازی مجدد اگر Secrets خالی است باید لینک دستی را وارد کنی؛ روش Share → Anyone with link به آن هم نیاز ندارد.*

**تذکر امنیتی مهم:** هر دو روش به داده‌ها دسترسی ناشناس می‌دهند: روش Anyone with link معمولاً امکان مشاهده کل شیت را فراهم می‌کند، و روش Publish to web فقط داده‌های تب منتشرشده را نشان می‌دهد. برای نرخ‌های محرمانه بدون انتشار عمومی، به یک روش احراز هویت دیگر یا یک واسط امن نیاز داریم؛ هیچ کد سمت Streamlit نمی‌تواند شیت خصوصی را بدون مجوز بخواند. رمز گذاشتن روی خود داشبورد، CSV منتشرشده را خصوصی نمی‌کند.

## نصب روی Streamlit

- محتویات ZIP را مستقیماً در ریشه مخزن GitHub قرار بده (فایل‌های `app.py`، `sheet_reader.py`، `fx_core.py` و `report_image.py` هم‌سطح باشند).
- فایل `requirements.txt` را هم جایگزین کن و در Streamlit **Reboot** بزن.
- اپ از قبل با شناسه شیت `1xckakJWtevb91dqlpbW504SbLg2irhhxlIRHIuTF3Ow` و `gid=982784865` برای تب `Rates_Log` تنظیم شده است.
- اگر شیوه انتشار فقط Rates_Log را انتخاب می‌کنی، لینک خروجی آن را یک بار در سایدبار Paste کن.

## منطق محاسبات

- نرخ مؤثر بانک = نرخ خام × (۱ − کارمزد اظهار ÷ ۱۰۰). عدد `0.6` در ستون E یعنی ۰٫۶ درصد.
- نرخ مؤثر کوتاژ = نرخ کوتاژ؛ نرخ مؤثر بازار آزاد = نرخ بازار آزاد.
- اختلاف نرخ = نرخ بازار آزاد − نرخ مؤثر.
- درصد اختلاف = ۱۰۰ × اختلاف ÷ نرخ بازار آزاد.
- معادل دلاری اختلاف = حجم مبنا × اختلاف ÷ نرخ بازار آزاد.
- برای هر ترکیب «نوع مسیر + منبع»، جدیدترین تاریخ ثبت‌شده استفاده می‌شود؛ در تاریخ‌های مساوی آخرین ردیف.
- تصویر ۱۰۸۰ × ۱۳۵۰ برای واتس‌اپ، جدول و تاریخچه CSV همچنان وجود دارد.
