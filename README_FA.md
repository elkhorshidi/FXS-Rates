# Helios | FX Obligation — نسخه MVP

اپلیکیشن Streamlit برای مقایسه آخرین نرخ‌های «بازار آزاد، بانک‌ها و کوتاژ» از Google Sheets. ورودی و تاریخچه **فقط** در شیت `Rates_Log` نگهداری می‌شود؛ اپ **خواندنی** است و هیچ رکوردی را تغییر نمی‌دهد.

## مشخصات
- استخراج خودکار **آخرین نرخ هر ترکیب «نوع مسیر + منبع»**؛ حتی اگر نام بانک «ملی» باشد، نه «بانک ملی».
- کارمزد اظهار برای بانک‌ها به درصد (ورودی `0.6` یعنی **۰٫۶٪**)؛ نرخ مؤثر = نرخ خام × (۱ − درصد÷۱۰۰).
- اختلاف تومان/دلار = بازار آزاد − نرخ مؤثر؛ اختلاف درصدی = اختلاف÷آزاد×۱۰۰.
- معادل دلاری کل اختلاف = حجم دلار × اختلاف تومان/دلار ÷ نرخ بازار آزاد.
- گزارش PNG فارسی به ابعاد 1080×1350 و انتخاب تا ۷ مسیر؛ جدول آخرین نرخ‌ها، تاریخچه و CSV خروجی.
- ریفرش دستی یا خودکار حداکثر هر ۲ دقیقه در Streamlit.
- استفاده از فونت **Vazirmatn** برای صفحه از Google Fonts؛ تصویر تلاش می‌کند هنگام اجرا فونت متن‌باز را از ریپازیتوری رسمی دریافت کند. فایل فونت در ZIP قرار ندارد.

## شیوه استقرار در Streamlit Community Cloud
1. فایل‌های پروژه را داخل یک مخزن GitHub خصوصی یا عمومی آپلود کنید (نه خود ZIP، محتویات آن). `app.py` در ریشه باشد.
2. در [share.streamlit.io](https://share.streamlit.io) پروژه را با **Main file path = `app.py`** مستقر کنید.
3. از [Google Cloud Console](https://console.cloud.google.com) یک پروژه و Service Account بسازید. **Google Sheets API** را فعال کنید و از Service Account یک JSON Key بگیرید. (فرآیند رسمی: [Streamlit Private Google Sheets](https://docs.streamlit.io/develop/tutorials/databases/private-gsheet).)
4. در شیت `Helios | FX Rate History` روی **Share** بزنید و `client_email` حساب سرویس را با سطح **Viewer** اضافه کنید.
5. در تنظیمات Streamlit App → **Secrets**، محتوای `.streamlit/secrets.example.toml` را با مقادیر واقعی JSON جایگزین کنید و **یک `dashboard_password` اختصاصی** انتخاب کنید. Secrets را در GitHub ذخیره نکنید.
6. Reboot/Rerun کنید؛ با رمز ورود صفحه بالا بیاید. برای محدود کردن دسترسی به داشبورد از رمز استفاده کنید؛ خصوصی بودن خود Sheet به‌تنهایی به معنی خصوصی بودن UI Streamlit نیست.

## استفاده آزمایشی بدون اتصال Google
قبل از ایجاد Secrets می‌توانید CSV برگرفته از شیت `Rates_Log` را از قسمت **File → Download → CSV** دریافت و در نوار کناری اپ آپلود کنید. این حالت **زنده نیست**.

## نمونه ساختار ردیف
| زمان (تهران) | نوع مسیر | منبع | نرخ خام | کارمزد (%) |
|---|---|---|---:|---:|
| تاریخ و ساعت | بازار آزاد | بازار | … | 0 |
| تاریخ و ساعت | بانک | ملی | … | 0.6 |
| تاریخ و ساعت | کوتاژ | بازار | … | 0 |

**توجه:** ستون A باید تاریخ و ساعت واقعیِ ثابت باشد، نه فرمول `NOW()` متغیر. این اپ از ورودی‌های واقعی خوانده‌شده استفاده می‌کند، نرخ جدید خلق نمی‌کند. هر استعلام تازه باید در ردیف **جدید** ثبت شود، نه جایگزین ردیف قبلی.

## اجرای محلی
```
python -m pip install -r requirements.txt
streamlit run app.py
```

## راهنمای فایل‌ها
- `app.py`: داشبورد، بارگذاری داده و گزارش.
- `fx_core.py`: محاسبات و استخراج آخرین نرخ.
- `report_image.py`: خروجی PNG.
- `.streamlit/config.toml`: تنظیمات رنگ و ظاهر.
- `.streamlit/secrets.example.toml`: نمونه اتصال محرمانه، **فاقد اطلاعات واقعی ورود**.
- `tests/test_fx_core.py`: تست منطق نرخ‌ها.

## امنیت
Service Account فقط با مجوز `spreadsheets.readonly` استفاده می‌شود؛ شیت عمومی منتشر نمی‌شود. قرار دادن اپلیکیشن روی Streamlit Community Cloud باعث عمومی‌شدن نشانی آن می‌شود؛ قبل از وصل کردن حساب سرویس، رمز داشبورد را در Secrets تعیین کنید.
