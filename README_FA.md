# HELIOS FX Dashboard — نسخه ۳.۱ (اصلاح نمایش گزارش تصویری در Streamlit Cloud)

**این نسخه فقط یک اصلاح سازگاری مهم برای تولید PNG دارد؛ اتصال Google Sheets، نرخ‌ها، CSS و محاسبات تغییر نکرده‌اند.**

## نصب فوری در مخزن موجود GitHub

1. فایل `report_image.py` نسخه ۳.۱ را دانلود کنید.
2. در ریشه مخزن فعلی، فایل `report_image.py` قبلی را با همین فایل جایگزین کنید.
3. تغییر را Commit کنید و صبر کنید Streamlit نسخه جدید را اجرا کند؛ در صورت لزوم Reboot app را بزنید.
4. دوباره بخش «گزارش تک‌صفحه‌ای مشتری» را باز کنید. ساخت تصویر نباید دیگر خطای `KeyError` مربوط به RTL بدهد.

`requirements.txt` باید شامل `Pillow`، `arabic-reshaper` و `python-bidi` باشد. در نسخه ۳ این سه مورد وجود دارند و نیازی به تغییر Secrets یا Google Sheets نیست.

## علت رفع‌شده

در نسخه ۳، حتی وقتی libraqm در Pillow نصب نبود، `ImageDraw.textlength(..., direction="rtl")` اجرا می‌شد؛ Pillow در آن وضعیت `KeyError` می‌دهد. نسخه ۳.۱ این پارامتر را فقط در صورت پشتیبانی به کار می‌گیرد؛ در محیط بدون libraqm، با `arabic-reshaper` و `python-bidi` متن فارسی را شکل‌دهی و با حالت ساده رسم می‌کند.

برای نصب کامل تازه، فایل‌های ZIP را در ریشه مخزن قرار دهید. اگر قبلاً نسخه ۳ را روی Streamlit اجرا کرده‌اید، فقط جایگزینی `report_image.py` کافی است.

## تست

`python -m unittest discover -s tests -v`

۱۲ تست شامل سناریوی بدون libraqm پاس شده‌اند.

# HELIOS | FX Obligation Dashboard — نسخه ۳ (Redesign)

داشبورد بازطراحی‌شده برای مقایسه نرخ بانک‌ها، کوتاژ و بازار آزاد. **داده‌ها فقط از `Rates_Log` در Google Sheets خوانده می‌شوند** و منطق محاسبات و اتصال بدون Google Cloud همان نسخه ۲ است.

## جایگزینی نسخه فعلی (۳ دقیقه)

1. `helios_fx_dashboard_v3.zip` را از حالت فشرده خارج کن.
2. **محتویات داخل پوشه** را در *ریشه مخزن GitHub فعلی* قرار بده، در کنار `app.py`. در GitHub گزینه **Add file → Upload files** را بزن و فایل‌های ریشه را جایگزین کن، همچنین `tests` و `.streamlit/config.toml` را به‌روز کن. پوشه `.streamlit` مخفی است؛ اگر آپلود پوشه مخفی دشوار بود، لازم نیست `config.toml` را جایگزین کنی (استایل داخل کد هم اعمال می‌شود).
3. مهم: `requirements.txt`، `app.py`، `report_image.py` و فایل **جدید** `ui_styles.py` حتماً باید در مخزن حاضر باشند؛ `sheet_reader.py` و `fx_core.py` هم همراه بسته‌اند.
4. **Commit changes** کن. سپس از Streamlit **Manage app → Reboot app** یا Rerun را بزن.
5. چند لحظه صبر کن؛ نرخ‌ها باید خودکار از شیت خوانده شوند. روی «دریافت آخرین نرخ‌ها» کلیک کن و خروجی PNG را تست کن.

*اگر GitHub اجازه آپلود کامل پوشه نمی‌دهد:* می‌توانی فایل‌های پایتون و `requirements.txt` را به‌صورت تکی با **Upload files** آپلود کنی. تنظیمات Streamlit قبلی محفوظ‌اند و لازم نیست Secret جدیدی بسازی.

## تغییرات طراحی نسخه ۳

- هدر جمع‌وجور سرمه‌ای با هویت HELIOS
- ۴ کارت KPI با اعداد بزرگ و خوانا
- جدول RTL اختصاصی با برچسب نرخ برتر و هایلایت ردیف اول؛ امکان اسکرول در موبایل
- بخش گزارش مشتری با پیش‌نمایش و دکمه دانلود واضح، به‌همراه متن قابل کپی
- سایدبار فشرده‌تر، تاریخچه در بخش بازشونده
- گزارش واتس‌اپ ۱۰۸۰ × ۱۳۵۰ با **راست‌به‌چپ واقعی**، اعداد لاتین برای جلوگیری از باگ نمایش اعداد، فونت فارسی سازگار و مقایسه تصویری درصد اختلاف وقتی تعداد مسیر کم است
- فونت Vazirmatn برای رابط وب با fallback؛ برای PNG، فونت در زمان اجرا دانلود می‌شود و در نبود دسترسی از فونت فارسی سیستم استفاده می‌شود؛ **هیچ فایل فونتی داخل بسته قرار ندارد**.

## فرمول‌ها (بدون تغییر)

```
Effective bank rate = Raw bank rate × (1 − declaration fee % / 100)
Gap (toman per USD) = Free market rate − Effective rate
Gap (%) = Gap / Free market rate × 100
USD equivalent = Gap × USD volume / Free market rate
```

کارمزد اظهار برای بانک‌ها یک **عدد درصدی** مثل `0.6` است. در مسیر بازار آزاد و کوتاژ کارمزد صفر لحاظ می‌شود.
